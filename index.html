For agents

A design system for ideas, not pixels

The Ugly Wireframe Kit is a complete, intentionally lo-fi toolkit – the components, patterns, and tokens you need to lay out a product, all drawn to look hand-sketched. The roughness is the point: when a screen looks unfinished, people critique the structure, the flow, and the content instead of debating color and corner radius. It's the fastest way to put an idea in front of someone and keep the conversation on the only question that matters early – does this actually work?

2 · Write semantic HTML
<div class="wf">
  <button class="wf-btn wf-btn--primary">Save</button>
  <span class="wf-tag">Launch</span>
  <i class="wf-icon" data-icon="check"></i>
</div>
Conventions
  • Wrap any subtree in .wf to inherit the font, color, and box-sizing.
  • Every block prefix is wf-; modifiers use -- (e.g. .wf-btn--primary).
  • Edges wobble via the #wf-rough-1/2/3 filters — drawn on a ::before so text stays crisp. Add .wf-edge--r2/--r3 to vary repeated shapes.
  • Tokens are CSS variables (--wf-ink, --wf-space-4…) — restyle the whole system by overriding them. Full set also in wireframe-tokens.json.
  • Icons: <i class="wf-icon" data-icon="NAME">; tint with color, size with font-size.
